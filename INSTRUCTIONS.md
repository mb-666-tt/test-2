# Project setup and ci/cd pipeline instructions
1. Use node, pnpm, next.js & tailwindcss to create a web application
2. Make sure it generates a static website
3. Use git to version control your code
4. Use github to host your code
5. Use vercel to deploy your static website to
6. Automate the deployment process using github actions and vercel - use free stuff only
7. On commit to master/main branch, github actions should run and deploy the website to vercel

# Project description
This project is a simple website which can be used as a portfolio website. It should have a dark mode and light mode. It should have a navigation bar with links to different sections of the website. It should have a contact form. It should have a footer with links to different social media platforms. It should have a responsive design. 

# Design instructions

# Page contents
1. Home
2. About
3. Projects
4. Contact
5. Footer

# Page content instructions
1. Home - simple landing page to quickly identify that this is a website for a construction 1-man company which takes care of small construction tasks such as prace wykończeniowe, glazurnicze i innych małych zadań budowlanych.
2. About - page with information about the company, its history, and the company owner.
3. Projects - page with information about the projects the company has worked on. It should have a gallery of images of the projects organized in a grid. Ideally hero image to each gallery should have a movable divider to show before and after images of the project.
4. Contact - page with a contact form. It should have a form with fields for name, email, and message. It should have a submit button.
5. Footer - page with links to different social media platforms.
